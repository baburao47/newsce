Variables and Constants

A variable is not a box that holds a value. It is a name tag that points to a value stored in memory.

The idea

x = 10 makes the name x point to the value 10.

y = x does not copy anything. Both names now point to the same value.

Reassigning, like x = 20, moves only the name tag x to a new value. y stays where it was.

Constants: Python has no real constants. By convention, names in UPPERCASE such as PI = 3.14 mean “please do not change this.”
