Loops in Python

A for loop repeats the same block once for every value in a sequence.

The idea

range(start, stop, step) makes the numbers. The loop variable takes the next value on every repeat, called an iteration.

range(1, 5) gives 1, 2, 3, 4.

Remember: the stop value is not included. The dashed circle below shows where the range stops.
